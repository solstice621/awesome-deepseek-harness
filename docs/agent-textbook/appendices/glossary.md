# Agent 工程术语表

[教材目录](../README.md)

本表给出教材使用的工程含义。同名词在三个项目中可能有不同边界；出现差异时，以章节中的固定源码定义为准。

| 术语 | 本书中的含义 | 常见混淆 |
|---|---|---|
| Agent 智能体 | 根据目标、观察与约束选择动作并吸收反馈的系统 | 不等于模型本身或多个 prompt |
| Model 模型 | 将输入映射为生成输出的决策组件 | 输出一个动作不等于执行动作 |
| Harness | 围绕模型组织上下文、工具、策略与反馈的系统 | 不是仅指 prompt 模板 |
| Runtime 运行时 | 承担执行、状态、调度、资源生命周期的程序 | 不一定与 harness 是独立进程 |
| Workflow 工作流 | 路径和约束主要提前编码的流程 | 可与动态 Agent 决策组合 |
| Policy 策略 | 决定动作选择或准入的规则 | 模型策略与权限策略不是同一对象 |
| Observation 观察 | 从环境取得的有限证据 | 不是完整世界状态 |
| Action 动作 | 对环境的查询或改变 | 计划文字不是已经执行的动作 |
| Feedback 反馈 | 动作后用于调整决策的观察 | 不必是数值奖励 |
| Partial observability 部分可观测 | 系统只看到环境状态的一部分 | 长上下文也不能自动补全未读取事实 |
| Session 会话 | 一段有关联的历史和运行状态 | 不等于一个 HTTP 连接 |
| Turn 轮次 | 项目定义的一次用户或调度驱动的执行单元 | 一个 turn 可以含多次模型请求 |
| Step 步骤 | 项目定义的逻辑决策或执行步 | 不一定等于一次 HTTP attempt |
| Attempt 尝试 | 某次逻辑操作的物理请求尝试 | 重试不一定新建逻辑 step |
| Event 事件 | 某个状态变化或观察的记录 | UI 临时事件不必持久化 |
| Projection 投影 | 从历史或状态计算出的某种视图 | 与源记录的内容和寿命可以不同 |
| Artifact 制品 | 可检查、可交付的文件或其他产物 | 最终回答中的描述不是文件本身 |
| Tool 工具 | 具有输入输出契约的可调用动作 | schema 不提供完整权限控制 |
| Tool call 工具调用 | 模型或程序发出的具体调用请求 | call ID 不是天然幂等键 |
| Schema 模式 | 对数据形状和部分约束的描述 | 语法有效不等于业务正确 |
| Provider 供应商适配 | 将模型或服务协议接入运行时的层 | 换 URL 不能完成协议兼容 |
| Streaming 流式输出 | 分批交付生成片段和终态信息 | 文本显示完成不等于调用结算 |
| Token | 模型计量输入输出的单位 | 同名 usage 字段的缓存口径可不同 |
| Context window 上下文窗口 | 单次请求可使用的上下文容量约束 | 不是长期持久存储 |
| Context engineering 上下文工程 | 选择、排序、约束、更新模型可见信息 | 不仅是写系统提示词 |
| Instruction hierarchy 指令层级 | 不同来源指令的优先与适用规则 | 检索到的文本不能自行获得高权限 |
| RAG 检索增强生成 | 先取回证据再生成回答或动作的流程 | 不必使用向量数据库 |
| Embedding 嵌入 | 将内容表示为便于相似度比较的向量 | 相似不证明真实、最新或有权访问 |
| Memory 记忆 | 可在后续任务中保存与使用的信息体系 | 需区分工作状态、日志、摘要和经验 |
| Compaction 压缩 | 重构较短的模型可见上下文 | 不是无损备份 |
| Skill 技能包 | 可复用的指令与资源组合 | 不自动授予执行权限 |
| Plugin 插件 | 经扩展契约参与系统行为的模块 | 安装、激活和可调用是不同阶段 |
| MCP | 用于连接模型应用与工具资源服务的协议体系 | 接入协议不自动提供可信授权 |
| Admission 接纳 | 系统正式接受某项输入或执行意图 | 接纳成功不等于任务完成 |
| Snapshot 快照 | 某个边界上捕获的一致状态视图 | 不保证外部文件随后不变 |
| Cancellation 取消 | 发出停止意图并传播至执行边界 | 不自动回滚已发生副作用 |
| Backpressure 背压 | 消费速度不足时限制生产或缓冲 | 无上限排队不是可靠流处理 |
| Retry 重试 | 在条件满足时再次尝试操作 | 不证明不会重复副作用 |
| Idempotency 幂等性 | 同一语义操作重复提交不会重复改变目标效果 | 需要身份、参数与保存范围一致 |
| At least once 至少一次 | 操作或交付可能重复，但目标是至少发生一次 | 消费者通常需去重或协调副作用 |
| Exactly once 恰好一次 | 在明确系统边界内，语义效果只发生一次 | 单机去重不能普遍保证跨服务效果 |
| Checkpoint 检查点 | 足以支持特定继续方式的保存状态 | 保存存在不证明任意位置均可恢复 |
| Flush 持久性屏障 | 请求把已接受写入推进到接口承诺的持久边界 | 不同后端的承诺需具体核对 |
| Claim 执行声明 | 系统持久记录存在正在执行的意图 | 不证明外部工具尚未执行 |
| Approval 批准 | 主体对明确范围动作的许可 | 不是操作系统隔离 |
| Sandbox 沙箱 | 限制进程对资源访问的执行边界 | 一个名为 full 的模式不能替代检查实际策略 |
| TOCTOU | 检查与使用之间状态变化的竞态 | 批准旧参数不能无条件覆盖新参数 |
| Prompt injection 提示注入 | 不可信内容试图影响指令或行为边界 | 单句提醒不能证明风险消除 |
| Delegation 委派 | 把有范围的任务交给另一执行主体 | 子 Agent 回答仍需证据与验收 |
| Goal 目标 | 可跨轮次持续管理的任务意图 | 不等于当前 turn 一直不结束 |
| Trace 轨迹 | 关联请求、工具、状态和结果的运行记录 | 日志存在不等于观察完整 |
| Evaluation 评测 | 用明确样本和标准衡量任务表现 | 模拟测试通过不证明真实模型能力 |
| Ground truth 独立预期 | 用来判定正确性的外部标准 | 不应直接复制被测模型的自评 |
| Rollback 回滚 | 在规定范围恢复之前状态 | 无法自动撤销外部不可逆动作 |

建议读者为所研究的项目再建一张“术语—类型—持久位置—终态”表。它能帮助识别不同仓库之间看似同名、实际语义不同的对象。
